# 📋 首頁導覽改版計畫書（三層下鑽 + 進度條系統）

> 目標：解決「一進首頁看到 36 張考卷」的資訊爆炸問題，改成
> **國考 → 年度 → 科目** 三層下鑽，每層字卡都顯示學習進度條。
> 同時保留多國考擴充性（未來可加入物理治療師等）。

---

## 一、使用者流程（目標體驗）

```
🏠 首頁（第 0 層：國考列表）
└─ 📋 職能治療師　（進度條：1,234 / 2,880 題 · 43%）
       │  ← 點卡片進入
       ▼
📅 年度選擇（第 1 層）
├─ 🗓 115 年　（進度條：480 / 480 · 100%）
├─ 🗓 114 年　（進度條：320 / 480 · 67%）
├─ 🗓 113 年　（進度條：0 / 480 · 0%）
└─ ...（110–112）
       │  ← 點年度進入
       ▼
📚 科目選擇（第 2 層）＋ 練習模式
├─ 🔬 解剖學與生理學　（進度條：60 / 80 · 75%）
├─ 📖 職能治療學概論　（進度條：80 / 80 · 100%）
├─ 🦴 生理障礙職能治療學（進度條：12 / 80 · 15%）
└─ ...（共 6 科）
       │  ← 勾選科目 → 選模式 → 開始練習
       ▼
✏️ 練習頁（現有功能不變）
```

**未登入**也能看到進度（本機紀錄）；**登入後**進度 = 雲端＋本機合併。

## 二、進度條系統設計

### 2.1 「完成」的定義（建議）
| 定義 | 說明 |
|---|---|
| **完成 = 作答過一次**（建議） | 該題最新作答紀錄存在即算完成，答對答錯都算「做過」 |
| 輔助顯示：答對率 | 卡片進度條下方加一行小字「答對率 72%」，考生一眼看弱點 |

> 理由：衝刺複習的「刷過一輪」本身就值得獎勵；答對率另外呈現，不混在完成度裡。
> 錯題重練後（答對）→ 最新紀錄更新 → 答對率同步上升。

### 2.2 進度資料來源
- **本機**：localStorage（`ot_review_attempts_v1`，`[{qid, ok, picked, ts}]`）
- **雲端**：Firebase `users/{uid}/attempts`（登入後自動合併，現有機制）
- **計算方式**：每題取「最新一筆」紀錄 → 完成題數 = 有紀錄的題數

### 2.3 每層進度條顯示
| 層級 | 進度條內容 |
|---|---|
| 國考卡 | 完成 X / 總題數（例：1,234 / 2,880）+ 答對率 |
| 年度卡 | 該年度完成 X / 480 + 答對率 |
| 科目卡 | 該科完成 X / 80 + 答對率 |

### 2.4 進度條視覺
- 三色漸層：0–33% 紅／33–66% 橙／66–100% 綠（或統一藍色＋完成打勾）
- 卡片右上角：百分比大字
- 100% 時卡片出現 ✅「已完成」標記
- 答題後返回任一層，進度即時更新（無需重新整理）

## 七、設計決定（已確認 2026-08）

| 決定 | 結果 |
|---|---|
| 「完成」定義 | **答對才算完成**（最新作答紀錄為答對的題數；卡片另顯示「作答 X 題 · 答對率 Y%」小字，資訊完整） |
| 科目層 | **保留多選**（可跨科隨機出題） |
| 年度排序 | **最新在前**（115 在最上面） |
| 進度條顏色 | **三色漸層**（0–33% 紅 / 33–66% 橙 / 66–100% 綠） |

### 進度計算公式（依「答對才算完成」）

```
對每題取「最新一筆作答」:
  完成度 = 最新作答為答對的題數 ÷ 該層總題數
卡片小字 = 已作答 X 題（含答錯）· 答對率 Y%（答對÷作答）
```

> 例：某科 80 題，作答 50 題、答對 40 題
> → 進度條 40/80 = 50%（三色：橙）
> → 小字「作答 50 題 · 答對率 80%」
> 錯題重練把錯題答對後 → 進度條自動上升。
