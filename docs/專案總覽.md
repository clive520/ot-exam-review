## 🏗 架構

```
考選部 PDF(試題/答案/更正答案)
  → scripts/01~08 管線(文字→CSV→清洗→圖片→SQLite→JSON)
  → db/questions.db (SQLite, 唯一真源)
  → app/data/questions.json (Web 用)
  → GitHub Pages (GitHub Actions 自動部署)
  → Firebase (Google 登入 + Firestore 雲端同步 + 問題回報)
```

## ✨ 功能

- 科目/年度多選、🎲隨機出題、🔢依序練習、📕錯題重練
- 作答即時核對 + 答案內容 + 官方更正備註 + 圖片題
- 錯題本、各科弱點統計（正確率）
- 🔑 Google 登入：作答紀錄雲端同步（換裝置不遺失）
- ⚠ 問題回報（登入後每題可回報）+ 📥 管理員後台（狀態追蹤）
- 📤 匯出/📥 匯入本機紀錄（備份）
- 多選答案支援（Ｃ、Ｄ都給分）
- PWA 安裝 + 離線使用
