# 🆕 新增其他國考指南（例如：物理治療師、呼吸治療師…）

> 系統設計為多國考可擴充：資料庫有 exam_types 層、管線腳本完全通用。
> 只要照以下步驟，新國考的考古題就能加入同一個網站。

## Step 1：取得 PDF

1. 考選部網站（https://www.moex.gov.tw）→ 考畢試題查詢 → 選定考試與年度
2. 下載該考試的 **試題 PDF**、**答案 PDF**、**更正答案 PDF**（有的話）
3. 放到本機一個年度資料夾，例如 `PT/`（物理治療師）

## Step 2：跑轉檔管線

```powershell
# 假設物理治療師 113 年度, 科目編碼為 51~56 之類(依考選部代號)
# 1. 建立資料夾 + 提取文字 + 建 CSV + 套更正 + 清洗
#    (若編碼格式與職能治療師相同, 可直接用 run_year.ps1; 不同則依樣修改)
powershell -File pdf_sop/scripts/run_year.ps1 PT113 old
```

> ⚠ 若題號/選項/答案鍵格式不同（例：複選題、答案鍵為 1~4），先人工檢視 exam.txt/ans.txt，再調整 `02_build_csv.js` 的解析規則（見 SOP v2 第 1 節）。

## Step 3：術語查證（品質保證）

1. 每科清洗後，用子代理（或人工）稽核可疑專有名詞（流程同職能治療師）
2. 彙整確認清單 → 使用者確認 → 寫入各科 `term_fixes.json` → 重跑 03

## Step 4：匯入資料庫

建立新國考的 db_config（複製 `115/db_config_all.json` 修改）：

```json
{
  "examType": { "code": "PT", "name": "物理治療師" },
  "subjects": [ { "year": 113, "code": "51", "name": "物理治療學概論", "csv": "PT/51/最終.csv" } ]
}
```

```powershell
node pdf_sop/scripts/07_import_db.js PT/db_config.json db/questions.db
node pdf_sop/scripts/08_export_json.js db/questions.db app .
```

## Step 5：部署

```powershell
cd repo
Copy-Item ..\app\data\* data\ -Force
Copy-Item ..\app\images\* images\ -Recurse -Force
git add . && git commit -m "新增物理治療師題庫" && git push
```

GitHub Actions 會自動部署 → 網站首頁自動出現「🏥 物理治療師」入口（App 依 meta.json 的 examTypes 自動產生分組）。

## Step 6：驗收

- [ ] 首頁出現新考試類型，科目卡片正確（年度 × 科目）
- [ ] 隨機/依序/錯題重練都正常
- [ ] 圖片題顯示正常
- [ ] 抽 5 題核對題目/選項/答案一致

## 注意事項

| 項目 | 說明 |
|---|---|
| 科目編碼 | 不同考試的編碼不同（11~66、0105~0805、51~56…），run_year.ps1 的 codes/map 需調整 |
| 題數 | 有些考試 80 題/科，有些 50 或 100 題，02 的驗證不硬性要求 80 |
| 複選題 | 若為「複選題」考試（非單選），需要改 App 的作答邏輯（目前支援官方多選答案但 UI 為單選作答） |
| 圖片 | 有「圖中/下圖」題才需要跑 04/06；可先掃描 exam.txt |
